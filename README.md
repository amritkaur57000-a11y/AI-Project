# BotEvolution — Interactive AI Experience

A static HTML, CSS and JavaScript educational website. No Python, Flask, build tools, API keys or server are required.

## Run in VS Code
1. Extract the ZIP.
2. Open the `BotEvolution-Platform` folder in VS Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` → **Open with Live Server**.

You can also open `index.html` directly in a modern browser.

## What's inside
- Product-style landing page and responsive navigation
- Four AI approach cards with explainer modals
- Interactive evolution timeline
- Four-way prompt comparison using transparent local educational simulations
- Knowledge Lab: paste notes or upload a `.txt` file, then retrieve keyword-matching passages locally
- Emerging AI topics: multimodal, agentic, edge and foundation models

## Important limitations
This is a frontend educational prototype. The ELIZA, expert-system and neural-network outputs are simplified demonstrations, not production AI models. The RAG-style area demonstrates local keyword retrieval, not embeddings, vector databases, or an LLM. No uploaded text is sent to a server. PDF parsing, real voice recognition, image understanding and live LLM APIs are not connected.
